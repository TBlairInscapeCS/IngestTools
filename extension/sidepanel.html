One click: reads the request email from any open Outlook tab, loads the tracker (from the email's sheet link - no tab needed - or an open tracker tab), matches rows, then downloads: direct links first, then the ER search sweep, then open delivery pages. 2 · Tracking sheet?
The client tracker - loaded automatically from the email's sheet link, a focused sheet tab, or any open tracker tab (an Airtable tab is read via the app's own copy, which covers every row, not just visible ones). Paste tracker is the manual fallback: click a grid cell, Cmd+A, Cmd+C, then the button. Column mapping auto-detects; adjust under the mapping row if the sheet is unusual.

3 · Match?
Pairs email codes with sheet rows. Rows whose Link cell holds a real URL can download right here. Label-only sources (Extreme Reach, Yangaroo) go to step 4. INGESTED = already done per the sheet's fill-back columns. Files land in ~/Downloads/Ingest/<job>/.
4 · Download files?
Open pages reads every delivery list open in the browser (ER Spot Deliveries tabs + the focused page) - only what's on screen; flip pages and press again to accumulate.
ER search queries Extreme Reach directly: every Inscape TV delivery in the day window, all pages. Optional sender filter reads each delivery's "Trafficked By" (e.g. tatari); with matched IDs loaded it only sender-checks those rows. No page needed open - just be logged into ER.

5 · Ingest portal?
Fills the Vizio Inscape Portal (portal.cognet.tv) ingest queue. Check portal verifies the customer name against the playbook and lists queued files. Preview fills shows exactly what would be written per row - Reporting ID, Title, Advertiser/Brand/Vertical, Fingerprint - before anything touches the page. Push fills writes them into the queue cells and keeps watching for files dropped later. _ticker files get fingerprint=video per playbook. Realm, Type, and Retention are never touched - defaults stand. BEGIN INGEST stays your click.
