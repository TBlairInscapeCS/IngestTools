Ingest Streamlined

Request email → tracking sheet → matched rows → downloaded media → filled portal queue → Jira proof → reply.

How a job flows

  1. Request - open the request email in Outlook on the web; the panel grabs it, detects the client, and pulls the codes it asks for.
  2. Tracker - the tracking sheet loads from the email's link, an open sheet tab, or a manual pick. Matched rows show their line numbers - click one to highlight it in the sheet.
  3. Match - email codes ↔ sheet rows. Exclude any row that doesn't belong; nothing downstream sees it.
  4. Download - Find & download tries direct links, then the Extreme Reach sweep, then open delivery pages.
  5. Portal - feeds files into portal.cognet.tv's ingest queue and fills Reporting ID / Title / Advertiser / Fingerprint. Standard batch first; _ticker versions build automatically and feed as a separate video-only batch.
  6. Report - verify the records, review the drafted ticket, post to Jira when you're happy, copy the reply back to the requester.

The download watcher macOS, recommended checking…

A small local service (ingest_watch.py) makes the file pipeline hands-off: it watches ~/Downloads/Ingest/, pairs arrivals to manifest rows, spec-checks media with ffprobe, builds _ticker versions, feeds files to the portal picker, and archives finished jobs under Documents/Customer Content/.

  • Full package: unzip it, then double-click watcher/install.command - it installs to ~/Library/Application Support/IngestTools/ and starts it at login via launchd.
  • From the repo: local/README.md covers the same install plus the launchd plist.
  • Needs: macOS, python3, and ffmpeg/ffprobe (brew install ffmpeg) for the ticker builds and spec checks.

The extension works without it - matching, highlighting, Jira drafts - but downloads, tickers, and portal feeding need the watcher listening on 127.0.0.1:8770.

First run

Open a request email in Outlook on the web, open this panel from the toolbar icon, and press ▶ Run all. The panel walks the rest; every stage shows a status dot, and anything destructive (BEGIN INGEST, Post to Jira) is always your click.
