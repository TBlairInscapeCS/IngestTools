Your first job (5 clicks)

Request
Open the request email in Outlook, press Run all. It reads the email, picks the client and tracker tab, and matches the IDs. Check the Document title - wrong tracker is the #1 mistake.
↓
Files
Review what Run all found, then press Download files. The watcher specs them and builds ticker versions in the background.
↓
Ingest
Feed files → Check & preview → Accept fills → BEGIN INGEST on the portal. Ready tickers feed themselves as batch 2.
↓
Confirm
Verify & draft checks records and drafts the Jira ticket and reply. Both post only when you say so.

Stuck? The sticky job summary and the suggested next-action button always show what's missing. Jump to any step at any time - every module works on its own.

Beyond the basics - manual paths, trackerless clients, client rules

No IDs in the email? Small pending pools auto-commit; otherwise highlight the request rows on the tracker and press Match sheet selection. Trackerless clients (ComScore, SimulMedia) hide the tracker - use Identify email IDs.

Manual file handling: I already have the files searches Downloads/Ingest; Use portal file picker selects files on the portal without a manifest; ZIPs in the job folder unpack themselves. I already ingested them jumps to Confirm and checks records.

Delivery sources: the Search selector covers Extreme Reach (auto-expands 2 → 7 → 14 days), Comcast email, Yangaroo download links, open pages, and local discovery.

Client rules: Edit selected client rules overrides tracker requirement, sender domains, ingest realm, Jira epic, ER filter, and ticker settings - saved locally in this Chrome profile only.

Naming: portal Title defaults to Reporting ID unless the client's rules say otherwise; ComScore tickers use lowercase _t. InMarket fills Advertiser/Brand/Vertical from each row's InMarket Campaign Name (column D). Internal Vizio requests ingest into both geniusdigital and vizio silos.

Housekeeping: Stop downloads stays in the header while a job downloads. Clear all resets the request without touching logs, sign-ins, settings, media, or portal records. Advanced settings → Show all steps (advanced) restores the expanded view.
